# @galaxyproject/orbit-browser

Orbit's shell for the browser: the agent in a Web Worker, its model providers, the chat and
artifact panes, and the Galaxy transport. A flavor mounts it and adds its own tools, skills,
artifact kinds and launch context; `@galaxyproject/olit`, the Galaxy visualization plugin, is the
first. See LAYOUT.md at the workspace root for the package exports and the extension seams.
